# 🤖 Telegram Bot: Basketball Rules

Jupyter/Colab-ноутбук: Telegram-бот, который отвечает на вопросы по правилам баскетбола с помощью ИИ.

---

## 🏀 О проекте

- Бот принимает вопросы по правилам баскетбола и отвечает на них, используя базу знаний и OpenAI API.
- Позволяет переводить запросы, искать ответы по эмбеддингам, выдаёт осмысленные ответы на русском языке.
- Ноутбук написан для Google Colab — отлично подходит для быстрой демонстрации и тестирования.

---

## 🚀 Как запустить

1. Открой `basketball_rules_bot.ipynb` в [Google Colab](https://colab.research.google.com/) или Jupyter.
2. Установи необходимые библиотеки (см. ячейки в начале ноутбука).
3. Введи свои API-ключи для Telegram и OpenAI.
4. Следуй шагам в ноутбуке.

---

## 📦 Состав репозитория

- `basketball_rules_bot.ipynb` — основной ноутбук проекта

---

## 📸 Пример

```

Пользователь: "Что такое пробежка?"
Бот: "Пробежка — это нарушение, когда игрок делает более двух шагов с мячом без ведения."
```
